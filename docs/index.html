What is Elevate?

Elevate is a climbing gym operations app in development, with a front desk view for staff and a dashboard for members.

Can my gym use it today?

Not as a production service. The screens shown here are a working preview using mock data. Please don’t enter real climber or payment information.

Are memberships and payments live?

No. The preview can show membership and waiver status, but buying or renewing a membership and processing payments are not available.

How much does it cost?

Pricing has not been set or published. There is no paid plan or trial to start at this stage.

Where can I get help or share feedback?

Use the project’s GitHub issue tracker for questions and feedback. It is public, so don’t include passwords, personal information, or real customer records.
